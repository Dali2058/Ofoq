# أفق — منصة ذكاء اصطناعي متكاملة (نسخة أولية)

شات بذاكرة، رفع ملفات وصور، بحث على الإنترنت، وإنشاء ملفات قابلة للتنزيل (Word / PDF / Excel / PowerPoint / أكواد)، مع حسابات وخطط استخدام يومية.

## التشغيل

```bash
npm install
cp .env.example .env     # (لو مفيش .env) وحط AI_API_KEY جواه
npm run check-ai         # يتأكد إن مفتاح الذكاء الاصطناعي شغال
npm start                # http://localhost:3000
```

يتطلب Node.js 20 أو أحدث.

## ضبط مزوّد الذكاء الاصطناعي

أي مزوّد متوافق مع واجهة OpenAI (`/chat/completions` مع دعم الأدوات) يشتغل بتغيير 3 قيم في `.env`:

| المزوّد | AI_BASE_URL | AI_MODEL |
|---|---|---|
| AIMLAPI | `https://api.aimlapi.com/v1` | `google/gemini-3-5-flash` (راجع الاسم الصحيح في وثائقهم) |
| Google AI Studio | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-2.5-flash` |
| Groq | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` |

> الطبقات المجانية لها حدود طلبات وقد تتغير. لو الموقع هيتفتح للجمهور، راقب الاستهلاك وحدد خطط الاستخدام في `server/config.js` بما يناسب رصيدك.
> رؤية الصور وتنفيذ الأدوات يعتمدان على الموديل: لو الموديل ما بيدعمهم هتلاقي أخطاء من المزوّد.

## الهيكل

```
server/
  index.js    الخادم: المسارات، الرفع، الشات (SSE)، حدود المعدل
  auth.js     التسجيل والدخول (bcrypt + JWT في كوكي httpOnly)
  ai.js       الاتصال بالمزوّد + حلقة الأدوات (بحث، إنشاء ملفات، ذاكرة)
  files.js    قراءة PDF/Word/Excel + توليد docx/xlsx/pptx/pdf
  search.js   Tavily (لو في مفتاح) أو DuckDuckGo
  db.js       SQLite: مستخدمين، محادثات، رسائل، ذاكرة، ملفات، استهلاك
  config.js   الخطط والحدود
public/       الواجهة (HTML/CSS/JS بدون build)
scripts/check-ai.js
```

## الأمان (المطبّق)

- مفتاح الذكاء الاصطناعي على الخادم فقط، ولا يوصل للمتصفح.
- كل استعلام على المحادثات والملفات والذاكرة مقيّد بصاحب الحساب (مختبَر).
- كلمات المرور مشفّرة (bcrypt)، والجلسة في كوكي `httpOnly` + `sameSite=lax` (و`secure` في الإنتاج).
- حدود معدل على الدخول والرفع والشات، وحد يومي حسب الخطة.
- رفع الملفات بقائمة امتدادات مسموحة وحد 15 ميجا، والتنزيل بـ `nosniff`.
- ردود الذكاء الاصطناعي تُنقّى بـ DOMPurify قبل العرض، مع CSP عبر helmet.

## تغيير خطة مستخدم (لحد ما تضيف الدفع)

```bash
node -e "const D=require('better-sqlite3');new D('data/app.db').prepare('update users set plan=? where email=?').run('pro','user@example.com')"
```

الخطط: `free` (20 رسالة/يوم)، `pro` (200)، `max` (1000) — عدّلها من `server/config.js`.

## الإنتاج

- اضبط `NODE_ENV=production` وشغّل خلف HTTPS (Nginx/Caddy أو منصة استضافة).
- ثبّت `JWT_SECRET` بقيمة عشوائية طويلة.
- احفظ مجلد `data/` على تخزين دائم وخد منه نسخ احتياطي (قاعدة البيانات والملفات).
- لا ترفع `.env` على GitHub (موجود في `.gitignore`).

## حدود النسخة الحالية (للتطوير التالي)

- الرد يوصل كامل بعد انتهاء المعالجة (الحالة اللحظية تظهر أثناء البحث والإنشاء، لكن مفيش بث كلمة بكلمة).
- ملفات PDF بالعربي تجريبية: ضع خط عربي في `fonts/arabic.ttf`، ولأفضل نتيجة اطلب Word للمحتوى العربي. الحل الأقوى لاحقًا: توليد PDF عبر Puppeteer.
- الدفع والاشتراكات (Stripe أو بوابة محلية) لسه ما اتربطتش.
- البحث بدون Tavily يعتمد على DuckDuckGo وقد يتعطل أو يتحدد؛ يُفضّل مفتاح Tavily.
- ملفات الصور تُقرأ كصور فقط (مفيش OCR للـ PDF الممسوح ضوئيًا).
